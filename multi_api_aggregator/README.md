# 🤖 Multi-API Async Aggregator (多 API 异步数据聚合器)

本项目是基于 Python 3.11 + `asyncio` 构建的工业级数据高并发清洗管道。系统并发请求天气、新闻、汇率三大异构网络终点，完成异构数据的自动打平（Flatten）与脱水清洗，并流式固化到本地结构化 CSV 报表中。

## ✨ 核心特性
- **多轨并发**: 对齐前端 `Promise.all` 心智，利用 `aiohttp` 实现单核高并发网络 I/O，耗时缩短 70%。
- **工程化守卫**: 全量覆盖 `typing` 类型注解，100% 遵循 PEP 8 命名与空行规范。
- **鲁棒防崩**: 模块间配备 `if __name__ == "__main__"` 沙箱拦截，防范非正常导入带来的生存期污染。
